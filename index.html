Selected work

Clarity

Personal project, in development

A note-taking system for people with ADHD. Most of the engineering ended up going into one question that isn't really about notes: when is a note allowed to leave the system?

I built it so a note can only reach a third-party AI service once someone has explicitly turned that on, and wrote a test that fails if a single request escapes while it's off. Serverless on AWS: Lambda, API Gateway, DynamoDB and Cognito, with a React front end. 121 tests.

Not deployed. The repository is private for now, so the case study is the evidence rather than the code.

An Apple Pay checkout that only failed on iPhones

BlueBow Group, 2025

A payment SDK update went out and checkout kept working in desktop Chrome, so nothing looked wrong. On mobile Safari, Apple Pay failed. I ran the tests, traced it to a change in how the SDK processed the token, and supported the release of the compatibility fix.

The rest of the internship was integration work on a React and TypeScript product: third-party authentication and analytics, Jest regression tests, developer onboarding documentation, and device management across Intune, Jamf and Apple Business Manager. Most of the specifics are confidential.

Storage writes in a voting contract

Contribution to a group project

A blockchain voting system built by a small team. The running tally was written back to contract storage on every pass of a loop, and persistent writes are the expensive operation on-chain. I worked out that it could accumulate in memory and be written once after the loop finished. Another contributor implemented it in Solidity.
