01

Personal project · 2025 to now

Clarity

A note-taking system for people with ADHD. Most of the engineering went into one question that isn't really about notes: when is a note allowed to leave the system?

Status
In development, not deployed
Tests
270 passing on 4 November 2026
Built with
JavaScript Lambda handlers on the Serverless Framework, with API Gateway, DynamoDB, Cognito and React
Next
AWS CDK in TypeScript, decided but not built

What it shows

  • A note can only reach a third-party AI service once its owner has switched that on, and the server won't switch it on without consent on record.
  • The test for that watches the network, not the code. It points the AI SDK at a recorder and fails if a single request arrives while the feature is off.
  • Ten ownership tests try to reach another user's notes from every direction, including listing, search and export.

02

TypeScript · React · TanStack Query

A dashboard's data fetching, before and after

Reconstruction, written from scratch with a simulated API. Not company code.

One dashboard screen calling the same simulated API two ways, with a toggle between them and a counter for every call.

Before
Each panel fetches on mount: one endpoint requested twice, a request that waits for its parent's to finish, and nothing kept between tabs
After
A shared query layer: one request per endpoint, all started together, and cached across tabs
In the demo
The overview makes six API calls before and four after. Going back to a tab makes none.
How it's counted
Tests that click through the app and check every request, plus the on-screen counter. React StrictMode is left off because it would double only the "before" count, and a test shows that too

03

Group project · 2024 · my contribution was the optimisation, not the Solidity

Storage writes in a voting contract

A blockchain voting system built by a small team. The running tally was written back to contract storage on every pass of a loop, and persistent writes are the expensive operation on-chain. I worked out that it could accumulate in memory and be written once after the loop finished. Another contributor implemented it in Solidity.

About

A diploma in Lagos, agency work there, then London for the degree. I finished with a First in Information Technology while leading shifts at Marks & Spencer, sorting out customer problems as they came in. Retail doesn't leave you time to deliberate. You fix what's actually in front of you and move to the next thing, and that reflex has been more useful in engineering than I expected going in.
